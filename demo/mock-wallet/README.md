# Demo mock wallet

A demo-only Chrome extension that mimics the Freighter external API (the
`window.postMessage` protocol spoken by `@stellar/freighter-api`) so the pool console
can be recorded end-to-end — connect, deposit, withdraw, owner pages — without a real
browser wallet.

- Loaded into a throwaway Chrome profile for the demo recording. Modern Chrome ignores
  `--load-extension`, so `scripts/record-demo.mjs` injects the built bundle into the page
  directly; the manifest remains for loading the extension by hand in a normal browser.
- Signs with the `stellar-alice` / `stellar-admin` **testnet** identities from the
  Stellar CLI keystore. The active identity is `localStorage["demo.identity"]`
  (`alice` by default, `admin` for owner scenes), read at request time.
- `build/inject.js` is generated by `scripts/build-demo-wallet.mjs` and is gitignored —
  it contains testnet secrets, so it must never be committed or used on mainnet.
