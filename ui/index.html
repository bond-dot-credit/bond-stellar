Meridian · Stellar testnet demo

Balances, shares, and confirmed transactions are read from Stellar testnet. The USDC token is a faucet-funded test token. The RWA aggregator and its yield are simulated; no real RWA investment occurs.

Connect a testnet wallet → fund XLM → get test USDC → deposit → watch keeper allocation → recall liquidity → withdraw.
